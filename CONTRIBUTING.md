# Contribution Guidelines

This repository is a collaborative academic project for the courses **Computer Architecture and Organization** and **History of Computing**.

## Team workspace

Each team works only inside its assigned directory:

`groups/group-XX/`

Do not modify another team's files or course administration files unless the instructor explicitly authorizes it.

## Working on the project

1. Update the file(s) requested for the current activity inside your team's folder.
2. Use clear Markdown and organize technical information with headings, diagrams and references when appropriate.
3. Review the content with the team.
4. Commit and push the changes.
5. Confirm that the final version is visible in the repository.
6. Submit the delivery through a GitHub Issue following `SUBMITIONS-GUIDE.md`.

## Commit messages

Use short, descriptive messages. Recommended pattern:

`group-XX: update <topic>`

Examples:

`group-01: update bus architecture`

`group-07: add memory hierarchy diagram`

`group-03: revise historical context`

## Weekly submissions

Weekly deliveries are officially registered through **GitHub Issues**, not through Pull Requests.

Only one member of the team opens the submission Issue. Follow the title, fields and checklist defined in:

**[SUBMITIONS-GUIDE.md](SUBMITIONS-GUIDE.md)**

If the instructor requests corrections, update the repository and reply to the same Issue with the new commit or file link.

## References

Maintain the sources used by the team in `groups/group-XX/references.md`. Prefer official documentation, technical manuals, books, scientific articles and institutional academic sources.
