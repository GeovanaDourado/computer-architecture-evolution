## Overview

This repository hosts the semester-long collaborative project developed by students enrolled in:

- Computer Architecture and Organization
- History of Computing

The project investigates the historical evolution of computer architectures while analyzing their technical organization and influence on modern computing.

---

## Objectives

Students will

- Understand historical milestones
- Analyze computer architectures
- Learn Git and GitHub
- Practice collaborative software development
- Produce technical documentation
- Present technical and historical analyses

## Weekly Workflow

Every week students will:

1. Read the weekly Issue
2. Create a branch
3. Complete the assigned task
4. Open a Pull Request
5. Receive feedback
6. Merge after approval

---

## Final Product

A public digital museum describing the evolution of computer architectures.
