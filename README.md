## Overview

This repository hosts the semester-long collaborative project developed by students enrolled in:

- Computer Architecture and Organization
- History of Computing

The project investigates the historical evolution of computer architectures while analyzing their technical organization and influence on modern computing.

## Objectives

Students will:

- understand historical milestones in computing;
- analyze computer architectures and their organization;
- connect hardware concepts to real architectures;
- practice collaborative work with Git and GitHub;
- produce technical documentation;
- communicate technical and historical analyses.

## Repository structure

```text
groups/          Team project documentation
docs/            Shared project documentation
presentations/   Presentation resources
website/         Digital museum / final website
assets/          Shared assets
```

Each team has its own directory under `groups/group-XX/`.

## Weekly workflow

The official workflow is:

`ACTIVITY → RESEARCH → UPDATE TEAM FILES → REVIEW → COMMIT/PUSH → SUBMIT ISSUE → AVA (when required)`

Weekly submissions are registered through **GitHub Issues**. The complete rules, required title pattern and submission checklist are available in:

### [SUBMITIONS-GUIDE.md](SUBMITIONS-GUIDE.md)

The Issue is the submission record; the complete technical content remains in the team's files in the repository.
